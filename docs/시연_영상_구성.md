# 공모전 시연 영상 (권장 90초)

## 실제 동작 장면을 중심으로

- 0–10초: 길튠 제목, 문제 제기 — "운전 중 음악을 바꾸느라 화면을 보지 않아도 된다".
- 10–25초: 길튠 실행, 재생 버튼 **한 번만** 누르기. 자체 데모 음원 재생, GPS/날씨 UI 보여주기.
- 25–55초: 지도에서 가상 주행 시작. **'가상 주행 시연' 표시를 화면에 유지**. 양화대교 접근과 진입을 동시에 보여주며 자동 전환 확인.
- 55–70초: 양화대교 통과 후 일반 도로 트랙 복귀. 버튼 조작 없이 음악이 이어짐.
- 70–80초: 미디어 제어에서 일시정지/다음곡 테스트 (실제로 확인된 경우만 영상에 포함).
- 80–90초: 사용자 가치·SDK 실제 연동 범위·향후 연결 목표 명시.

## 차량 SDK가 연결된 후 추가 장면

- Pleos Virtual Console 와이퍼 Off→On → **Vehicle SDK 콜백 로그** → 앱 우천 음악 추천 변화.
- Pleos 차량 위치 변경 → **FusedLocation SDK 콜백 로그** → 지도와 음원 변화.
- NaviHelper 주행 이벤트 수신 → 선곡 근거 표시.
